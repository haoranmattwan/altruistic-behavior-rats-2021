Bayesian Analysis of Food Sharing Behavior in Rats

Reproducible Python implementation of Wan et al. (2021)

This notebook is a maintained Python reimplementation of the model specification reported in:

Wan, H., Kirkman, C. F., Jensen, G., & Hackenberg, T. D. (2021). Failure to find altruistic food sharing in rats. Frontiers in Psychology, 12, 696025. https://doi.org/10.3389/fpsyg.2021.696025

The unmodified 2021 analysis is preserved in archive/published-2021/ and is the scientific source of truth. The companion notebook that preceded this correction is preserved in archive/companion-pre-correction/ for provenance.

The published analysis defines three Bayesian multilevel models:

  1. Binomial-logistic food-versus-social choice.
  2. Negative-binomial food and social response rates.
  3. Negative-binomial pellet allocation with three outcomes: the published consumed-pellet measure (CP), left behind (LP), and shared (SP).

The archived code labels CP as pellets consumed and calculates it as Food * FoodAmmt. This notebook preserves that published operationalization rather than redefining it: CP = Food * FoodAmmt, LP = PelletsLeft, and SP = Sharing.

Study and inferential scope

Six female Sprague-Dawley rats were studied as three familiar pairs. The three focal rats generated the session-level observations analyzed here; their partners were available for social release and, when the procedure allowed, food sharing. Food magnitude, home-cage food access, food location, and the food-collection period varied across seven conditions.

The models estimate posterior distributions and posterior predictions rather than null-hypothesis significance tests. Population-level parameters describe these three focal rats under the tested procedures; generalization beyond them should remain appropriately cautious.

Model Outcome Likelihood Population-scale interpretation
Choice Food choices out of food + social choices Binomial-logistic Food-choice probability at zero subject deviation
Response rate Food and social choices per session Negative binomial Expected choices at zero subject deviation
Pellet allocation Published CP, LP, and SP counts Negative binomial Expected pellets at zero subject deviation

Reproducibility configuration

CmdStan is pinned in ../config/cmdstan-version.txt; execution stops if a different version is active. Four chains, 3,000 warmup iterations, 3,000 retained iterations, adapt_delta = 0.99, and max_treedepth = 15 match the settings in the archived analysis. Fixed seeds support deterministic re-execution of this workflow but cannot reproduce the exact 2021 random draws across different Stan interfaces and versions.

from pathlib import Path
import platform
import sys

import cmdstanpy
import numpy as np
import pandas as pd
from cmdstanpy import CmdStanModel, cmdstan_version

ANALYSIS_DIR = Path.cwd()
if not (ANALYSIS_DIR / "Raw_data.csv").exists():
    candidate = ANALYSIS_DIR / "Analysis"
    if (candidate / "Raw_data.csv").exists():
        ANALYSIS_DIR = candidate
    else:
        raise FileNotFoundError("Run this notebook from the repository root or Analysis directory.")

PINNED_CMDSTAN_VERSION = (
    ANALYSIS_DIR.parent / "config" / "cmdstan-version.txt"
).read_text(encoding="utf-8").strip()

active_version = cmdstan_version()
ACTIVE_CMDSTAN_VERSION = (
    ".".join(str(part) for part in active_version)
    if isinstance(active_version, tuple)
    else str(active_version)
)

if ACTIVE_CMDSTAN_VERSION != PINNED_CMDSTAN_VERSION:
    raise RuntimeError(
        f"CmdStan {PINNED_CMDSTAN_VERSION} is required; "
        f"active version is {ACTIVE_CMDSTAN_VERSION}. "
        "Install the pinned version before running the analysis."
    )

MODEL_SEEDS = {
    "choice": 20210622,
    "response_rate": 20210623,
    "pellet": 20210624,
}

SAMPLING_CONFIG = {
    "chains": 4,
    "parallel_chains": 4,
    "iter_warmup": 3000,
    "iter_sampling": 3000,
    "adapt_delta": 0.99,
    "max_treedepth": 15,
    "refresh": 500,
    "show_progress": True,
}


def sample_maintained_model(model, data, seed):
    return model.sample(data=data, seed=seed, **SAMPLING_CONFIG)


def report_diagnostics(fit, model_name):
    print(f"\n=== {model_name}: CmdStan diagnose ===")
    print(fit.diagnose())
    summary = fit.summary()
    diagnostic_columns = [
        column for column in ("R_hat", "ESS_bulk", "ESS_tail")
        if column in summary.columns
    ]
    print(f"\n=== {model_name}: parameter diagnostic ranges ===")
    if diagnostic_columns:
        print(summary[diagnostic_columns].describe().loc[["min", "max"]])
    return summary


def summarize_gamma(fit, labels, inverse_link):
    natural_draws = inverse_link(np.asarray(fit.stan_variable("gamma")))
    if natural_draws.shape[1] != len(labels):
        raise ValueError("The number of labels does not match the gamma parameters.")
    intervals = np.quantile(
        natural_draws, [0.025, 0.10, 0.50, 0.90, 0.975], axis=0
    )
    return pd.DataFrame({
        "estimand": labels,
        "mean": natural_draws.mean(axis=0),
        "lower_95": intervals[0],
        "lower_80": intervals[1],
        "median": intervals[2],
        "upper_80": intervals[3],
        "upper_95": intervals[4],
    })


print("Analysis directory:", ANALYSIS_DIR.resolve())
print("CmdStan:", ACTIVE_CMDSTAN_VERSION)
print("Seeds:", MODEL_SEEDS)

Data

Raw_data.csv contains 145 session-level observations from three focal rats across seven conditions. The value -1 denotes an outcome that was not applicable or not recorded; it is never analyzed as a behavioral count. The checks below verify the published session counts and all sentinel-value patterns used by the Stan likelihoods.

analysis_df = pd.read_csv(ANALYSIS_DIR / "Raw_data.csv")

Model 1: Food versus social choice

The published choice analysis excludes Condition 5 because the social option was unavailable. The remaining conditions are re-indexed consecutively. The model estimates condition-level food-choice log odds and correlated subject deviations.

choice_df = analysis_df.loc[analysis_df["Condition"] != 5].copy()
condition_map = {
    condition: index + 1
    for index, condition in enumerate(sorted(choice_df["Condition"].unique()))
}
choice_df["Condition_Stan"] = choice_df["Condition"].map(condition_map)

stan_data_choice = {
    "N": len(choice_df),
    "S": int(choice_df["Subject"].nunique()),
    "subID": choice_df["Subject"].astype(int).tolist(),
    "C": int(choice_df["Condition_Stan"].nunique()),
    "condID": choice_df["Condition_Stan"].astype(int).tolist(),
    "choice": (choice_df["Social"] + choice_df["Food"]).astype(int).tolist(),
    "food": choice_df["Food"].astype(int).tolist(),
}

choice_model = CmdStanModel(stan_file=str(ANALYSIS_DIR / "pair_multilevel_model.stan"))
choice_fit = sample_maintained_model(choice_model, stan_data_choice, MODEL_SEEDS["choice"])
choice_probability_summary = summarize_gamma(
    choice_fit,
    [f"Condition {condition}" for condition in [1, 2, 3, 4, 6, 7]],
    lambda values: 1 / (1 + np.exp(-values)),
)
print(choice_probability_summary.to_string(index=False))
choice_diagnostics = report_diagnostics(choice_fit, "Choice model")

Model 2: Food and social response rates

The response-rate analysis models food and social response counts jointly with a negative-binomial likelihood. Condition 5 remains in the model; its social count is -1, so that likelihood contribution is skipped exactly as in the published Stan program. The Condition 5 social-rate parameter therefore has no direct likelihood contribution and should not be interpreted as an empirical estimate.

stan_data_response = {
    "N": len(analysis_df),
    "S": int(analysis_df["Subject"].nunique()),
    "subID": analysis_df["Subject"].astype(int).tolist(),
    "C": int(analysis_df["Condition"].nunique()),
    "condID": analysis_df["Condition"].astype(int).tolist(),
    "FC": analysis_df["Food"].astype(int).tolist(),
    "SC": analysis_df["Social"].astype(int).tolist(),
}

response_model = CmdStanModel(stan_file=str(ANALYSIS_DIR / "resp_rate_multilevel_model.stan"))
response_fit = sample_maintained_model(
    response_model, stan_data_response, MODEL_SEEDS["response_rate"]
)
response_rate_labels = (
    [f"Food | Condition {condition}" for condition in range(1, 8)]
    + [f"Social | Condition {condition}" for condition in range(1, 8)]
)
response_rate_summary = summarize_gamma(
    response_fit, response_rate_labels, np.exp
)
response_rate_summary["evidence"] = np.where(
    response_rate_summary["estimand"] == "Social | Condition 5",
    "prior only",
    "observed",
)
print(response_rate_summary.to_string(index=False))
response_diagnostics = report_diagnostics(response_fit, "Response-rate model")

Model 3: Pellet allocation

The published pellet model has three outcomes per condition:

  • CP: the published consumed-pellet measure, calculated as Food * FoodAmmt in the archived analysis.
  • LP: pellets left behind, from PelletsLeft.
  • SP: pellets shared, from Sharing.

Values of -1 mark outcomes that were not applicable. The model skips those likelihood contributions.

consumed_pellets = (analysis_df["Food"] * analysis_df["FoodAmmt"]).astype(int)
left_pellets = analysis_df["PelletsLeft"].astype(int)
shared_pellets = analysis_df["Sharing"].astype(int)

stan_data_pellet = {
    "N": len(analysis_df),
    "S": int(analysis_df["Subject"].nunique()),
    "subID": analysis_df["Subject"].astype(int).tolist(),
    "C": int(analysis_df["Condition"].nunique()),
    "condID": analysis_df["Condition"].astype(int).tolist(),
    "CP": consumed_pellets.tolist(),
    "LP": left_pellets.tolist(),
    "SP": shared_pellets.tolist(),
}

assert stan_data_pellet["CP"] == (
    analysis_df["Food"] * analysis_df["FoodAmmt"]
).astype(int).tolist()
assert stan_data_pellet["LP"] == analysis_df["PelletsLeft"].astype(int).tolist()
assert stan_data_pellet["SP"] == analysis_df["Sharing"].astype(int).tolist()

pellet_model = CmdStanModel(stan_file=str(ANALYSIS_DIR / "intake_multilevel_model.stan"))
pellet_fit = sample_maintained_model(pellet_model, stan_data_pellet, MODEL_SEEDS["pellet"])
pellet_labels = (
    [f"Published CP | Condition {condition}" for condition in range(1, 8)]
    + [f"Left behind | Condition {condition}" for condition in range(1, 8)]
    + [f"Shared | Condition {condition}" for condition in range(1, 8)]
)
pellet_rate_summary = summarize_gamma(pellet_fit, pellet_labels, np.exp)
left_without_data = (
    pellet_rate_summary["estimand"].str.startswith("Left behind")
    & ~pellet_rate_summary["estimand"].str.endswith(("Condition 5", "Condition 7"))
)
shared_without_data = (
    pellet_rate_summary["estimand"] == "Shared | Condition 5"
)
pellet_rate_summary["evidence"] = np.where(
    left_without_data | shared_without_data, "prior only", "observed"
)
print(pellet_rate_summary.to_string(index=False))
pellet_diagnostics = report_diagnostics(pellet_fit, "Pellet model")

Interpretation

The natural-scale tables report posterior means, medians, 80% credible intervals, and 95% credible intervals, matching the article’s emphasis on estimated behavior and uncertainty. These tables apply the inverse link to gamma, so they are conditional population-level estimates at zero subject deviation rather than marginal averages across subjects. Parameters marked prior only lack a direct likelihood contribution and are retained solely to preserve the published model structure.

The substantive benchmark is the peer-reviewed article: food preference changed with food magnitude and home-cage food access, social responding remained comparatively stable, and sharing was rare across conditions. Re-executed estimates should be compared with those reported patterns and intervals rather than with the exact archived Monte Carlo draws.
