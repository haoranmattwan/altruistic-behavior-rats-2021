Bayesian Analysis of Food Sharing Behavior in Rats

A Python Replication of Wan et al. (2021), Frontiers in Psychology

Project Objective

This notebook provides a complete, reproducible Python workflow for the Bayesian statistical analyses presented in the publication:

Wan, H., Kirkman, C. F., Jensen, G., & Hackenberg, T. D. (2021). Failure to find altruistic food sharing in rats. Frontiers in Psychology, 12, Article 696025. https://doi.org/10.3389/fpsyg.2021.696025

The study’s primary goal was to conduct a systematic replication to critically evaluate prior claims of altruistic food sharing in rats. The experiment involved rats choosing between food rewards and social interaction under varying conditions of food availability and motivation.

The data and original analysis scripts are available in the Supplementary Material of the original publication at the publisher’s website.

Analytical Approach

The analysis relies on Bayesian hierarchical generalized linear models implemented in Stan via the cmdstanpy package. This approach is well-suited for modeling behavioral data with repeated measures from a small number of subjects, providing robust estimates and full posterior inference. Specifically, we fit:

  1. A hierarchical binomial logistic regression to model the choice proportion between food and social interaction.
  2. A hierarchical negative binomial regression to model the counts of food and social responses, accounting for potential overdispersion in the count data.
  3. A hierarchical negative binomial regression to model the counts of food pellets consumed versus shared.

Analysis Workflow

  1. Setup: Load necessary Python libraries and the raw experimental data. Prepare data for Stan modeling.
  2. Model 1 (Choice Proportion): Fit and summarize the logistic regression model.
  3. Model 2 (Response Counts): Fit and summarize the negative binomial model for total food/social responses.
  4. Model 3 (Pellet Allocation): Fit and summarize the negative binomial model for consumed/shared pellets.

2. Model 1: Choice Proportion (Food vs. Social)

The first analysis models the rats’ preference between the food and social options. We use a Bayesian hierarchical binomial logistic regression to estimate the probability of choosing the food lever over the social lever in each experimental condition.

Model Structure: * Outcome: The number of Food choices out of the total Social + Food choices in each session. * Likelihood: Binomial distribution with a logit link function. * Predictors: Experimental condition (as a categorical variable). * Hierarchical Component: The model includes varying intercepts for each Subject within each Condition. This accounts for individual differences in preference and how those differences might change across conditions. The gamma parameters represent the population-level average log-odds of choosing food in each condition.

Data Subsetting: As noted in the publication, Condition 5 is excluded from this analysis because only the food lever was active (no social choice was available), making preference undefined for that condition.

Stan Model Code and Execution

The Python cell below performs the following steps: 1. Defines the Stan model code as a multi-line string. 2. Writes the code to a .stan file. 3. Compiles the Stan model using cmdstanpy. 4. Prepares the data dictionary required by the Stan model, including filtering out Condition 5 and re-indexing the remaining conditions sequentially. 5. Runs the MCMC sampler to draw samples from the posterior distribution. 6. Prints a summary table focused on the population-level coefficients (gamma), which represent the average preference in each condition on the log-odds scale.

# --- 2.1 Stan Model Definition (Binomial Logistic Regression) ---
from pathlib import Path

# Define the Stan code for the multilevel binomial logistic regression model.
# This model estimates the probability of choosing food, allowing the intercept (preference)
# to vary by subject and condition.
choice_model_code = """
data {
  int<lower=1> N;                // Number of observations (sessions)
  int<lower=1> S;                // Number of subjects (rats)
  array[N] int<lower=1> subID;   // Subject ID for each observation
  int<lower=1> C;                // Number of conditions (excluding Cond 5)
  array[N] int<lower=1> condID;  // Condition ID for each observation (re-indexed)
  array[N] int<lower=0> choice;  // Total choices (Food + Social) in session
  array[N] int<lower=0> food;    // Number of food choices in session
}

transformed data {
  // Vector of ones for simpler matrix math in beta calculation
  vector[S] u = rep_vector(1.0, S); 
}

parameters {
  // Parameters for the hierarchical structure (non-centered parameterization)
  matrix[C, S] z;                   // Standardized subject deviations
  cholesky_factor_corr[C] L_Omega;  // Cholesky factor of the correlation matrix for varying effects
  vector<lower=0>[C] tau;           // Scale parameters for varying effects (subject SDs per condition)
  row_vector[C] gamma;              // Population-level intercepts (mean log-odds per condition)
}

transformed parameters {
  // Calculate subject-specific intercepts (beta) for each condition
  // beta = population_mean + subject_deviation
  matrix[S, C] beta = u * gamma + (diag_pre_multiply(tau, L_Omega) * z)';
}

model {
  // --- Priors ---
  // Weakly informative priors
  to_vector(z) ~ std_normal();         // Standard normal for standardized deviations
  L_Omega ~ lkj_corr_cholesky(2);     // LKJ prior for correlation matrix
  tau ~ exponential(1.5);             // Exponential prior for scale parameters
  to_vector(gamma) ~ normal(0, 1.5);  // Normal prior for population means

  // --- Likelihood ---
  // The number of food choices follows a binomial distribution with a logit link.
  array[N] real mu;                   // Linear predictor on the logit scale
  for (n in 1:N) {
    mu[n] = beta[subID[n], condID[n]]; // Get the appropriate intercept
  }
  food ~ binomial_logit(choice, mu); 
}
"""

# --- 2.2 Compile Stan Model ---
print("--- Compiling Model 1 (Choice Proportion) ---")
# Define file path and write the Stan code
stan_file_choice = Path("stan_models/choice_model.stan")
stan_file_choice.parent.mkdir(parents=True, exist_ok=True)
stan_file_choice.write_text(choice_model_code)

# Compile the model using cmdstanpy
choice_model_compiled = CmdStanModel(stan_file=stan_file_choice)
print("Model 1 compiled successfully.")

# Re-index Condition IDs sequentially from 1 (required by Stan)
# Original conditions 1, 2, 3, 4, 6, 7 become Stan conditions 1, 2, 3, 4, 5, 6
condition_map = {cond: i+1 for i, cond in enumerate(sorted(data_subset_choice['Condition'].unique()))}

# Create the data dictionary for Stan

  "subID": data_subset_choice['Subject'].tolist(),

3. Model 2: Response Counts (Food and Social)

While the first model examined the rats’ preference (proportion of choices), this second analysis models the absolute rate of responding for food and social interaction in each session. This allows us to see if the experimental conditions affected the overall number of choices made, not just the distribution between the two options.

Model Structure: * Outcome: The number of Food choices and Social choices per session (modeled simultaneously). * Likelihood: Negative Binomial distribution. This is a generalization of the Poisson distribution that is appropriate for count data. It includes an extra parameter to account for overdispersion—the tendency for the variance in behavioral count data to be greater than the mean—which is common in this type of experiment. * Predictors: Experimental condition and response type (Food vs. Social). * Hierarchical Component: The model estimates a unique population-level log-rate (gamma) for each response type in each condition. It also includes varying intercepts for each Subject, allowing each rat’s baseline response rate to differ from the population average.

Stan Model Code and Execution

The Python cell below follows the same process as before: defining, compiling, preparing data for, and running a custom Stan model. The key difference is the use of a negative binomial likelihood to model the response counts. The summary table shows the gamma parameters, which represent the population-level log-rates for food choices (gamma[1] to gamma[7]) and social choices (gamma[8] to gamma[14]) in each of the seven conditions.

# --- 3.1 Stan Model Definition (Negative Binomial Regression) ---

# This model estimates the rate of Food and Social choices, accounting for
# overdispersion in the count data. It's more complex because it models two
# outcomes simultaneously.
rate_model_code = """
data {
  int<lower=1> N;                // Number of observations
  int<lower=1> S;                // Number of subjects
  array[N] int<lower=1> subID;   // Subject ID for each observation
  int<lower=1> C;                // Number of conditions
  array[N] int<lower=1> condID;  // Condition ID for each observation
  array[N] int<lower=0> FC;      // Food choices (counts)
  array[N] int SC;               // Social choices (counts), allows non-positive for NA handling
}

parameters {
  // Parameters are now size 2*C to model both Food and Social responses
  matrix[2*C, S] z;                 // Standardized subject deviations
  cholesky_factor_corr[2*C] L_Omega;// Cholesky factor of the correlation matrix
  vector<lower=0>[2*C] tau;         // Scale parameters for varying effects
  row_vector[2*C] gamma;            // Population-level log-rates
  real<lower=0> overdisp;           // Overdispersion parameter for the negative binomial
}

transformed parameters {
  // Calculate subject-specific log-rates (beta) for each response type and condition
  matrix[S, 2*C] beta = rep_matrix(gamma, S) + (diag_pre_multiply(tau, L_Omega) * z)';
}

model {
  // --- Priors ---
  to_vector(z) ~ std_normal();
  L_Omega ~ lkj_corr_cholesky(2);
  tau ~ exponential(1.5);
  to_vector(gamma) ~ normal(1, 1.5); // Prior centered at log(2.7) choices
  overdisp ~ exponential(1);

  // --- Likelihood ---
  for (n in 1:N) {
    // Food choices are modeled for all conditions (parameters 1 through C)
    FC[n] ~ neg_binomial_2_log(beta[subID[n], condID[n]], overdisp);
    
    // Social choices are only modeled if they are not NA (passed as -1).
    // The parameters are offset by C (i.e., parameters C+1 through 2*C).
    if (SC[n] >= 0) {
      SC[n] ~ neg_binomial_2_log(beta[subID[n], condID[n] + C], overdisp);
    }
  }
}
"""

# --- 3.2 Compile Stan Model ---
stan_file_rate = "rate_model.stan"
with open(stan_file_rate, "w") as f:
    f.write(rate_model_code)

print("--- Compiling Model 2: Response Rates (Negative Binomial) ---")
rate_model_compiled = CmdStanModel(stan_file=stan_file_rate)

# --- 3.3 Prepare Data for Stan ---
# The 'Social' column has NaN for Condition 5. Stan's integer type cannot handle
# NaN, so we fill these with -1. The Stan model uses an `if` statement to
# skip these observations during likelihood calculation.
stan_data_rate = {
    "N": len(analysis_df),
    "S": analysis_df['Subject'].nunique(),
    "subID": analysis_df['Subject'],
    "C": analysis_df['Condition'].nunique(),
    "condID": analysis_df['Condition'],
    "FC": analysis_df['Food'],
    "SC": analysis_df['Social'].fillna(-1).astype(int) # Fill NaN and convert to int
}

# --- 3.4 Run MCMC Sampler ---
print("--- Running MCMC Sampler for Model 2... ---")

    data=stan_data_rate,
    chains=4,
    parallel_chains=4,
    iter_warmup=1500,
    iter_sampling=1500,
    adapt_delta=0.95,
    max_treedepth=15,
    show_progress=False
)
print("Model 2 sampling complete.")

# Display a summary for the population-level parameters (gamma).
# gamma[1]..[7] are log-rates for Food choices; gamma[8]..[14] are for Social choices.
print("\n--- Summary of Population-Level Parameters (gamma: Log-Rates of Response) ---")

gamma_summary_rate = summary_rate[summary_rate.index.str.startswith("gamma")]

4. Model 3: Pellet Allocation (Consumed vs. Shared)

This final analysis addresses the central question of the study: do rats altruistically share food? We model the number of food pellets that were consumed by the focal rat versus the number that were shared (i.e., produced but left available for the partner rat).

This model allows us to directly quantify and test the rate of sharing behavior across the different experimental conditions, providing a direct test of the altruism hypothesis.

Model Structure: * Outcome: The number of Consumed_Food pellets and Shared_Food pellets per session (plus Pellets_Left_Behind where applicable). * Likelihood: Negative Binomial distribution, again used to correctly model overdispersed count data. * Predictors: Experimental condition and pellet type (Consumed vs. Shared vs. Left Behind). * Hierarchical Component: The model estimates a population-level log-rate (gamma) for each pellet type in each condition, with varying intercepts for each Subject.

Stan Model Code and Execution

The structure of this model is similar to Model 2, but it is expanded to handle three potential outcomes. The summary table for gamma will show the population-level log-rates for consumed pellets (gamma[1] to gamma[7]), left-behind pellets (gamma[8] to gamma[14]), and shared pellets (gamma[15] to gamma[21]).

# --- 4.1 Stan Model Definition (Negative Binomial for Pellet Counts) ---

# This Stan code models the counts of consumed, shared, and left-behind pellets.
pellet_model_code = """
data {
  int<lower=1> N;
  int<lower=1> S;
  array[N] int<lower=1> subID;
  int<lower=1> C;
  array[N] int<lower=1> condID;
  array[N] int<lower=0> CP;      // Consumed Pellets (counts)
  array[N] int LP;               // Left-behind Pellets (counts), allows -1 for NA
  array[N] int SP;               // Shared Pellets (counts), allows -1 for NA
}

parameters {
  // Parameters for the hierarchical structure (3*C for Consumed, Left, and Shared)
  matrix[3*C, S] z;
  cholesky_factor_corr[3*C] L_Omega;
  vector<lower=0>[3*C] tau;
  row_vector[3*C] gamma;
  real<lower=0> overdisp;
}

transformed parameters {
  // Calculate subject-specific log-rates (beta) for each outcome type and condition
  matrix[S, 3*C] beta = rep_matrix(gamma, S) + (diag_pre_multiply(tau, L_Omega) * z)';
}

model {
  // Priors
  to_vector(z) ~ std_normal();
  L_Omega ~ lkj_corr_cholesky(2);
  tau ~ exponential(1.5);
  to_vector(gamma) ~ normal(0, 1.5); // Prior centered at log(1) = 0 pellets
  overdisp ~ exponential(1);

  // Likelihood
  for (n in 1:N) {
    CP[n] ~ neg_binomial_2_log(beta[subID[n], condID[n]], overdisp);
    if (LP[n] >= 0) {
      LP[n] ~ neg_binomial_2_log(beta[subID[n], condID[n] + C], overdisp);
    }
    if (SP[n] >= 0) {
      SP[n] ~ neg_binomial_2_log(beta[subID[n], condID[n] + (2*C)], overdisp);
    }
  }
}
"""

# --- 4.2 Compile Stan Model ---
stan_file_pellet = "pellet_model.stan"
with open(stan_file_pellet, "w") as f:
    f.write(pellet_model_code)

print("--- Compiling Model 3: Pellet Allocation (Negative Binomial) ---")
pellet_model_compiled = CmdStanModel(stan_file=stan_file_pellet)

# --- 4.3 Prepare Data for Stan ---
# Stan's integer type does not support NaNs. We replace them with -1 and use
# `if` statements in the Stan model to skip those observations.
stan_data_pellet = {
    "N": len(analysis_df),
    "S": analysis_df['Subject'].nunique(),
    "subID": analysis_df['Subject'],
    "C": analysis_df['Condition'].nunique(),
    "condID": analysis_df['Condition'],
    "CP": analysis_df['Food'],  
    "LP": analysis_df['PelletsLeft'].fillna(-1).astype(int),
    "SP": analysis_df['Sharing'].fillna(-1).astype(int)
}

# --- 4.4 Run MCMC Sampler ---
print("--- Running MCMC Sampler for Model 3... ---")
pellet_model_fit = pellet_model_compiled.sample(
    data=stan_data_pellet,
    chains=4,
    parallel_chains=4,

    show_progress=False
